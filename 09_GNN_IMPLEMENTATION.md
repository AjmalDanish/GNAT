# Purpose

The AI Engine is responsible for learning graph structures and identifying anomalous communication patterns.

The first implementation will use a Graph Convolutional Network (GCN).

Future versions may include

- GAT
- GraphSAGE
- GIN
- Graph Transformers

---

# Objectives

The model shall

- Learn graph topology
- Learn node relationships
- Predict anomaly probability
- Generate node risk scores
- Save trained models
- Support inference

---

# Model Selection

Chosen Model

Graph Convolutional Network (GCN)

Reason

- Easy to understand
- Well documented
- Fast training
- Excellent for portfolio projects
- Strong baseline model
